# Сайт SMM-специалиста

Одностраничный лендинг (услуги, кейсы, тарифы, контакты). Запуск через Vite.

## Запуск

1) Установить зависимости:

```bash
npm i
```

2) Запустить dev-сервер:

```bash
npm run dev
```

Откройте URL из терминала (обычно `http://localhost:5173`).

## Сборка

```bash
npm run build
npm run preview
```

## Где править тексты

- Основная разметка: `index.html`
- Стили: `src/style.css`
- Логика (меню + форма): `src/main.js`
